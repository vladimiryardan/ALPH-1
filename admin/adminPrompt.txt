## UI Style

Use a clean professional Bootstrap admin style.

Requirements:

* Light background
* White cards
* Subtle borders and shadows
* Consistent spacing
* Clear typography
* Responsive tables
* Mobile-friendly
* Avoid excessive animations
* Avoid oversized components
* Keep the interface practical rather than decorative

Use Bootstrap utilities instead of excessive custom CSS.

Create a small admin-specific stylesheet only where Bootstrap utilities are insufficient.

## Code Structure

Keep the admin interface modular.
